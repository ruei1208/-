# 網站編輯說明

網站網址（啟用 GitHub Pages 後）：https://ruei1208.github.io/-/

## 改文字
1. 在 GitHub 打開 `docs/content.js`，按右上角鉛筆圖示（Edit this file）。
2. 修改引號 `'...'` 內的文字，不要刪掉引號、逗號與括號。
   - `<b>文字</b>` 會顯示為粗體。
   - `[1]`、`[5][6]` 會自動變成連到參考文獻的連結（編號對應 `references` 清單的順序）。
   - 以 `【待補】` 開頭的文字會顯示成橘色虛線框，提醒還沒有資料。
3. 按 **Commit changes**。約 1 分鐘後網站自動更新（重新整理網頁即可看到）。

## 網站中的圖
除了 Inventor 3D 圖（`images/` 內的兩張），其他圖都是依書面報告數據繪製的向量圖，定義在 `figures.js`，在 content.js 中以 `draw: '名稱'` 引用。若要改用照片，把該處的 `draw: '名稱'` 改成 `src: 'images/檔名'` 即可。

## 換圖片／補圖片
1. 在 GitHub 打開 `docs/images/`，按 **Add file → Upload files** 上傳圖片（建議 jpg/png、寬度 1600 px 以內）。
2. 到 `docs/content.js` 找到對應的 `src: ''`，改成 `src: 'images/你的檔名.jpg'`；`caption` 是圖說。
3. 若上傳的檔名和原本的一樣（例如直接覆蓋 `images/hub-motor.jpg`），就不用改 content.js。

常見位置：
| 要補的內容 | 在 content.js 的位置 |
|---|---|
| Inventor 爆炸圖 | `experiments.tabs` 第一個分頁 `figures` 的第三張 |
| 數據圖表分頁 | `experiments.tabs` 第二個分頁的 `text` 與 `figures` |
| 指導教授系所職稱、照片 | `team.advisor` 的 `unit`、`photo` |
| 組員照片 | `team.members` 各人的 `photo` |

## 檔案說明
- `content.js`：所有文字、數據、圖片路徑、參考文獻（平常只需要改這個）
- `images/`：圖片
- `figures.js`：網站自行繪製的圖
- `index.html`、`main.js`、`style.css`：版面與動畫
- `tailwind.css`：已編譯的樣式；若修改 `index.html`／`main.js` 中的 Tailwind class，需依 `build/tailwind.config.js` 第一行指令重新編譯
